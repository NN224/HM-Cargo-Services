# HM Cargo Services

A TanStack Start website for HM Cargo Services.

## Local development

```sh
npm install
npm run dev
```

The development server runs at `http://localhost:8080`.

## Production build

```sh
npm run build
```

The production output is generated with Nitro using the `cloudflare-module` preset.

## Technology

- TanStack Start
- React
- TypeScript
- Tailwind CSS
- Vite
- Nitro
